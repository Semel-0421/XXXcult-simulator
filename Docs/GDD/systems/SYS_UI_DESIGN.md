# SYS_UI_DESIGN — 인게임 UI·텍스트 개선 방향 (기획 초안)

작성: 2026-10-25. 근거: 플레이 모드 캡처(2560×1440, 메인·결과 그림·엔딩 도감·옵션), 코드(`UiKit`, `UiSkin`, 씬 글꼴 참조).
디자인 리뷰 도구: impeccable(critique 방식). Unity uGUI라 웹 감지기는 쓰지 않고, 화면 캡처와 코드만으로 판단함.
성격: 방향 제안. 구현·수치 변경 없음. 아래 "정할 것"이 정해지면 단계별로 진행.

## 1. 현재 상태 (확인한 사실)

- **글꼴 3종이 한 화면에 섞임.**
  - 씬 기본 글꼴은 `Fust&Schoeffer GoticoAntiqua`(라틴 블랙레터)로 135곳에서 씀.
  - 한글은 폴백으로 `MapoFlowerIsland`(손글씨)가 그려짐.
  - 상단 자원 바 라벨 14곳은 `MapoDacapo`.
  - 그래서 "교단 0년 3분기" 한 줄에서도 숫자는 블랙레터, 한글은 손글씨로 나옴.
- **글자 크기가 19종(13~80)으로 흩어져 있음.** 코드로 만든 창은 대부분 18·20·22, 제목은 34.
- **색 상수가 흩어져 있음.**
  - `new Color(...)` 117곳(UI 24파일).
  - 금색은 `UiKit.Gold`와 `UiSkin.Gold`에 중복 정의.
  - 패널 바탕은 창마다 다름: 메인은 보라, 엔딩 도감은 자주+빨강, 옵션은 갈색 바탕에 보라 버튼.
- **정체성 자산이 이미 있음.** 금실 박음질 책 표지(`UiSkin.BookFrame`), 월계관, 블랙레터 제목, 먹빛·양피지 색. 다만 메인 본문 패널과 엔딩 도감에만 쓰이고, 옵션·업적 창은 평범한 사각 패널임.

| P3 | 표기 다듬기 | "0레벨"(교리 0단계?), "25세·5회차", "덕목 평균 0·욕망 평균 0" 같은 표기는 뜻을 짐작해야 함. 상단 라벨이 작고 어두움 | 메인 캡처 |

**같이 발견한 버그 2건 (수정 완료, 2026-10-25)**
1. **업적 창이 장면 전환 뒤 열리지 않음.**
   - 증상: "destroyed Image" 오류.
   - 원인: 창은 씬과 함께 사라지는데 정적 목록 `rows`·`giftedCells`(`AchievementWindow`)와 `cells`(`GiftedGalleryView`)가 비워지지 않음.
   - 빌드에서 예상되는 경로: 시작 화면에서 업적 창 → 게임 시작 → 다시 업적 창.
   - 수정: 다시 만들 때 목록을 비움(`EndingGallery`·`AdultGallery`와 같은 방식).
   - 확인: 플레이 중 `LoadScene("GameMain")` 뒤 열림. EditMode 250/250.
2. **기프티드 도감의 해금 아이콘이 빈 네모(□)로 보임.**
   - 원인: `✦`가 프로젝트의 어느 글꼴에도 없음.
   - 수정: `†`로 바꿈(Mapo 글꼴에 있음). 화면에서 확인함.
   - 코드 문자열 안의 다른 특수 문자(− — → ≤ · …)는 한글 글꼴에 모두 있음. 블랙레터 글꼴에는 `·`만 있으나, 폴백으로 그려짐.

## 3. 개선 방향

### 3-1. 톤: "금박 필사본" 하나로 통일 (권장)

이미 있는 책 표지, 금실, 블랙레터, 월계관을 모든 창에 일관되게 씀. 새 세계관을 만들지 않고 지금 정체성을 끝까지 밀어붙이는 방향임.

- 장식은 **제목·틀·엔딩**에 집중함.
- 플레이 중 읽고 판단하는 영역(본문, 수치)은 **장식을 빼고 또렷하게** 함.

### 3-2. 글자 체계

| 역할 | 서체 | 크기(기준 1280×720) | 용도 |
|---|---|---|---|
| 장식 제목 | 블랙레터 + 한글 손글씨(꽃섬) | 34 / 28 | 창 제목, 엔딩 이름, 교단 이름 |
| 본문 | 읽기용 한글 명조(OFL 후보: Noto Serif KR, 나눔명조) | 22 | 이벤트 본문, 선택지 |
| 라벨 | 같은 본문 서체 | 18 | 스탯 이름, 버튼 |
| 수치 | 본문 서체의 고정폭 숫자(`<mspace>` 또는 tabular) | 20 | 자원·스탯 값 |
| 보조 | 본문 서체, 흐린 색 | 16 | 안내, 지난 결과 |

- 단계를 19종에서 5종으로 줄이고 `UiKit`에 상수로 둠.
- 블랙레터는 라틴 전용이므로, 숫자가 들어가는 줄(연도, 수치)에는 쓰지 않음.
- 영어 모드도 같은 표를 씀. 본문은 블랙레터 대신 읽기용 세리프로 함.

### 3-3. 색 토큰

`UiSkin`·`UiKit`의 색을 `UiPalette` 하나로 모으고, 창마다 직접 쓰던 117곳을 역할 이름으로 바꿈.

- **바탕**: 먹(가장 어두움) → 패널 → 행 → 버튼, 4단계.
- **글자**: 양피지(본문) / 금(제목·강조) / 흐림(보조).
- **상태**: 선택됨, 위험·닫기, 비활성. 같은 빨강을 두 의미로 쓰지 않음.
  - 선택됨: 금테+밝은 바탕.
  - 닫기·파괴: 진홍.

### 3-4. 메인 화면 레이아웃

1. **입력 하나로 정리.** 하단 행동 버튼 5개를 주 입력으로 하고 숫자키 단축을 버튼에 표시(예: `1 포교`). 본문 안 `[1] 포교` 안내와 번호 입력창은 선택지가 있는 이벤트에서만 보임.
2. **본문 패널 높이를 내용에 맞춤.** 남는 아래쪽에 "이번 턴 변화" 줄을 둠(예: `믿음 +6 · 봉헌금 +3 · 명망 −2`).
3. **수치 위계.** 상단 자원 중 판정에 직접 쓰는 3~4개(믿음, 신도, 명망, 봉헌금)를 크게, 나머지는 작게. 값이 바뀐 칸은 한 턴 동안 금테 강조와 ▲▼ 표시.
4. **결과 그림 위치.** 그림은 본문 위를 덮지 말고 본문 패널 오른쪽 위나 위쪽 띠에 둠. 덮어야 한다면 선택지가 나오기 전에 사라지게 함.

### 3-5. 창 공통

- `BuildScrollWindow`에 책 표지 틀을 기본으로 적용하고, 닫기 버튼 위치·색을 통일함.
- 스크롤이 있는 창은 아래쪽에 페이드와 스크롤바를 둠.
- 잠긴 카드는 "???" 대비를 높이고, 해금 조건 힌트 한 줄(업적 창 방식)을 둠.

### 3-6. 텍스트(카피)

- 수치 표기를 일관되게: "0레벨" → "교리 0단계", "25세·5회차" → "교주 25세 · 5번째 생".
- 결과 문장은 `(성공)`, `(실패)` 접두어 대신 색·아이콘으로 표시하고, 문장은 서술만 함.
- 안내문(placeholder)은 행동형으로: "번호 입력" → "번호를 누르거나 입력".
- 용어집 하나(믿음/신도의 믿음/신앙심/신앙 포인트 구분)를 `Lang.cs` 주석이나 Docs에 두고 표기를 맞춤.

- U4는 U1 뒤에 진행.

### (결정, 2026-10-25) 1·2·7

8절 시험 비교 결과를 보고 정함.

1. **톤**: 모든 창을 "금박 필사본"(책 표지 틀, 금실, 먹빛)으로 통일함.
2. **서체**: 역할별로 나눔.
   - 본문·라벨·수치: 일반 명조(OFL).
   - 버튼: 굵은 명조.
   - 창 제목, 교단 이름, 엔딩 이름, 욕망·덕목 머리글: 기존 블랙레터·손글씨 유지.
   - "Age · Run"처럼 정보를 담은 줄은 제목 서체에서 뺌.
3. **진홍(7번)**: 닫기·위험에만 씀.
   - 선택된 탭은 밝은 보라 + 금테.
   - 토글·이동 버튼은 기본 버튼색.
   - 모든 창의 닫기는 진홍(옵션 창 포함).

정할 것으로 남은 항목: 3(입력 방식), 4(상단 자원), 5(글꼴 용량), 6(결과 그림 위치), 8(문구의 결).

## 6. 미검증

- 거울 모드와 시작 화면은 캡처하지 않음.
- 1280×720 등 작은 해상도와 모바일(안드로이드) 비율은 실제로 보지 않았음. 크기는 2560×1440 캡처에서 환산한 값임.
- 영어 화면의 결과 창이 한국어로 나온 것은 언어를 결과 표시 중에 바꿨기 때문일 수 있음. 언어를 먼저 정하고 시작한 판에서 다시 볼 것.

## 7. Design 스킬 적용 결과 (2026-10-25 2차)

Anthropic Design 플러그인의 지침 4종을 적용함: design-critique, accessibility-review, ux-copy, design-system.
- 플러그인은 계정에 아직 설치되지 않아, 공개 원본(`anthropics/knowledge-work-plugins/design`)의 지침을 읽어 그대로 따름.
- 추가 캡처: 신 모드 메인, 권능 트리, 영어 메인.
- 대비는 캡처 픽셀을 측정함. 획 가장자리가 흐려지는 것을 빼지 않아 실제 대비는 조금 더 낮음.

### 7-1. 디자인 비평 (design-critique)

**첫인상 (2초)**
- 눈이 먼저 가는 곳은 금테 본문 패널과 결과 그림임. 그림이 가운데에 떠서 선택지를 가리므로, 시선이 "다음에 할 일"이 아니라 "지난 결과"에 머묾.
- 어둡고 금빛인 의식(儀式) 분위기는 바로 전달됨.

**사용성**

| 발견 | 심각도 | 권고 |
|---|---|---|

  - 버튼은 굵은체라 바탕체 시험보다 무게감이 있음.
  - 글자 넘침 점검: 화면 전체 중 2곳(교주 정보 줄, 연도 줄)이 경계를 살짝 넘음. 눈으로는 잘리지 않음.
- **예상과 다른 점**
  - Noto Serif KR의 한글은 획 대비가 약한 현대식 명조임. 게임 본문 크기(22)에서는 고딕에 가깝게 보여, 바탕체 시험만큼 "명조" 느낌이 나지 않음.
  - 큰 글씨에서는 삐침과 맺음이 보임.
- **용량**
  - 동적 아틀라스라 원본 OTF 두 개(7.7MB·7.9MB)가 빌드에 들어감. 웹 빌드가 약 15MB 늘어날 것으로 봄(빌드로 확인하지 않음).
  - 줄이려면 자주 쓰는 글자만 담은 정적 아틀라스로 바꿔야 함(정할 것 5).
- **아직 확인하지 않음**: 시작 화면, 거울 모드, 엔딩 창, 저장 창.
